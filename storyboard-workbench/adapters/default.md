# 默认适配：能力未知的宿主

适用于无法可靠确认运行环境、未登记的平台或显式 `--adapter default`。从 [Skill](../SKILL.md) 进入同一阶段工作流和字段合同；本文件不定义第二套导演规则，也不假设宿主会自动读取 `AGENTS.md`。

## 接入

在会话中明确要求读取完整 Skill 的 `SKILL.md`；只粘贴入口、未提供它引用的文件不构成完整安装。能执行脚本时运行：

```text
node "storyboard-workbench/scripts/runtime.mjs" rules plan --adapter default
```

`default` 不识别或切换宿主，实际平台记录为 `unknown`。模型选择独立；不知道实际模型时保留默认，不依据界面别名推测。

## 能力降级

| 观察到的限制 | 本次处理 |
|---|---|
| 不能读取文件或附件 | 明确缺少的路径/内容；由用户提供所需文件，不声称看过附件 |
| 可以读写，但不能执行脚本 | 保存符合共用合同的待校验 JSON，标“未执行硬校验”，给出共用终端检查命令 |
| 不能写文件 | 返回原始 JSON 文本供另存 UTF-8；不声称已生成 Excel |
| 不能理解图片 | 将对应图片核验保留未知；只使用可读取且有来源的文字事实 |
| 模型结果不能解析 | 保留原始输出和具体解析错误，不补造成功镜头 |
| 工具/网络失败或能力不支持 | 按宿主实际暴露的信息单独报告；不伪装成内容低分 |

以上是降级约定，不是已验证的平台能力。修复次数、语义核对及评分仍按共用流程，不能为了换平台无限重试。图片理解、原生 JSON 模式或工具调用能力均需真实证据；适配 Markdown 不能为模型安装或授予这些能力。
