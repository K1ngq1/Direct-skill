# 从工作流积累可复用经验

用户要求“沉淀 Prompt / 总结工作流 / 贡献经验”时使用本流程。这里的蒸馏是将案例提炼成有证据和适用范围的导演/Prompt方法；不训练模型权重，也不保证生成效果。

## 三层记录

| 层 | 内容 | 存放位置 |
|---|---|---|
| 原始案例 | 原始Prompt、节点来源、输入参考、模型与参数、修改版本、生成结果和用户评价 | 当前项目的 `experience/`，默认本地 |
| 候选经验 | 哪种写法解决什么问题、为什么可能有效、例外、反例、支持案例 | 本地 `experience/`，标记 candidate |
| 共享方法 | 审核后的经验、适用条件、来源案例、版本、已知限制 | Skill的 `knowledge/`，按任务读取 |

没有素材或结果时可以分析文字结构，但不能记录为“生成成功”。只读网页壳、公共示例和产品文案不属于用户的Prompt。记录未读取/部分读取的范围；不得拿助手已有方案冒充外部工作流内容。

## 读取和提炼

1. 从授权画布工具或用户导出文件读取实际节点及连线。逐条保留原文、来源节点、读取时间；画布位置只作为组织线索，连线、标题和内容共同判断工作顺序。
2. 区分文本备注、静帧生成、图像编辑、视频动作、声音、拼接等节点。参数和模型不在数据中时写 unknown，不从输出图外观反推为事实。
3. 分析主体/身份、场景/空间、镜头/构图、动作起止、风格/光线、参考用途、禁止变化项。将可变的故事内容与可复用写法分开；不要将所有句子都固定成模板。
4. 对比修改前后Prompt和实际结果，保留失败案例。用户采用某一方案是偏好证据；生成结果被实际视觉核验并满足要求，才是该场景有效的证据。模型自评分不能独立证明效果。
5. 输出少量有区别的候选方法，每条写清：问题、使用条件、建议做法、反例、证据、待验证项。只在相关任务检索，避免把整库塞进每轮上下文。

原始案例中的人物外观文字按来源留存；将经验用于本 Skill 新分镜时，遵守[角色资产引用规则](production-framework.md#角色设定与分镜引用)：分镜通过资产名称引用人物，详细外观留给角色三视图，不把旧案例的外观段落复制或隐藏拼入新分镜。

案例记录最少包含：稳定ID、source URL/项目ID/节点ID、原始Prompt、Prompt类型、模型/参数、参考资产与用途、用户目标、修改原因、实际结果、用户评价、视觉核验状态、分享许可。连接ID、临时授权URL和凭据不进入案例。支持未知字段，不编造缺失信息。

候选方法最少包含：ID、版本、标题、适用tags/模型或unknown、解决的问题、方法、适用条件、反例、证据案例ID、验证状态。单次成功标为单例经验；没有多案例验证就保留candidate。新证据只增补具体方法，不自动改写全局导演原则。

## 使用者贡献到GitHub

使用Skill不会自动给任何人仓库写权限，也不会自动上传本地项目。推荐的协作路径：

本地记录 → 使用者选择愿意公开的脱敏案例与候选方法 → Fork或获授权分支 → PR → 维护者核对来源/分享许可/效果证据/重复或冲突 → 合并 → 发布新版本。

贡献内容优先为方法、匿名案例和明确可分享的Prompt；参考图、人物照片、商业原稿及完整工作项目分别选择是否分享。授权读取工作流不等于授权公开发布。保留贡献者署名和所选内容许可证，不将“分享链接可访问”当成素材许可。

GitHub可以存储和版本化案例/方法；自动收集、审核和发布仍需明确配置的执行程序。第一阶段用PR即可，不设公共上传机器人或把仓库写凭据分发给使用者。未来若需要从网页一键贡献，另行实现身份验证、上传选择和PR创建，并验证实际权限。

现有安装副本不会随远端合并自动更新。使用者获取新版、重新加载Skill后才能使用新经验；发布记录说明新增方法和验证条件。原始工作项目与Prompt版本继续留在本地。

## 当前实现边界

已有工作台保存原稿、Prompt版本、选择、审核、逐格/范围批注和本地LibTV清单，可作为案例的来源；本文件增加Agent提炼/协作方法。范围要求按groupId及逐格差异追溯，不能把部分回应当作整组效果证据。清单prepared只代表准备、stale代表需重新核对，两者都不是已提交或生成成功。当前没有经验自动采集器、语义检索服务、GitHub同步机器人或模型训练任务。公共 `knowledge/` 仅在真实内容完成审核后创建，不预置伪成功案例。

GitHub的Fork/PR机制依据：[官方文档](https://docs.github.com/en/pull-requests/how-tos/create-pull-requests/creating-a-pull-request-from-a-fork)。
