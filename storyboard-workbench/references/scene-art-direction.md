# 场景美术与陈设设计

场景创作固定经过“场景信息 → 场景美术与陈设设计 → 场景 Prompt”。先理解空间怎样被使用、怎样容纳剧情，再组织可见画面；“丰富细节”“有生活感”不能代替具体设计。本规则是场景美术的共用入口，工作流、人物与机位规则引用它，不另建一套房间设定。

## 从脚本信息形成六项设计

每个必要场景按以下六项形成可检查的设计。它们是思考与核对维度，不是 Prompt 的固定段落，也不是物品数量配额。室外、交通工具或公共空间按实际功能处理不适用项，不强塞卧室式陈设。

| 设计项 | 必须具体说明的内容 |
|---|---|
| 空间用途与使用者 | 谁居住、停留或使用这里，空间承担什么功能；脚本或用户已给出的生活习惯及其依据。脚本没有提供真实职业、收入、身份、私人喜好时不补造事实；为本次虚构空间提出的使用习惯明确记为导演补全。不能靠堆书推断职业，不能靠昂贵家具推断收入。 |
| 核心布局 | 在统一的空间方位中安排门、窗、主要光源和床、沙发、桌柜等大件，说明彼此关系及人物进入、落座、伸手和离开的通道。先保留已确定布局；只有已知机位时才换算画面左右。无法从来源确定的方位作为导演方案登记，不能假称来自参考图。 |
| 陈设层次 | 先有承担功能的大件，再安排必要的中型收纳，最后选少量日用品；分别说明放在哪里、为什么在那里。卧室可有床和书桌、床下收纳箱、桌面的灯或水杯，公共空间则按服务、候坐和通行功能设计。无需每镜展示全部层次，不能只有家具名清单或“床和空墙”。 |
| 使用痕迹 | 选择与已知使用方式一致的少量痕迹并给出位置与状态，如摊开的书、椅背的外套、床头充电线、杯下的杯垫或轻微起皱的地毯。细节须服务使用者与当前时刻，不将凌乱、污渍或破损当作生活感的通用模板；人物已经拿走的东西不能仍固定在原处。 |
| 材质层次 | 区分墙面、木材、布料及其他必需材料的表面反应，例如哑光涂料墙、可辨木纹的桌面、略有褶皱的棉麻床品；说明相邻材料怎样在当前光线下被读清。避免所有物件均为光滑纯色，也不为追求质感虚构品牌、年代或精确工艺。 |
| 画面取舍 | 明确承载人物生活信息的丰富区、允许退后的背景区，以及人物动作、进出通道、主要家具轮廓和视觉焦点周围的留空区。细节的密度、对比与景深服务剧情；不能让收纳、装饰或零散用品遮挡手、脸、互动对象和必须读清的道具。 |

设计应能回答“谁在用、怎样使用、物件为何在这个位置”。脚本已经明确的物件与位置优先；普通布置可在已授权的导演设计范围内统一补全。生活感来自功能关系、材质差别和少量具体痕迹，不来自无差别增加物品。

## 保存设计与场景正文

复用场景资产文件合同：在 `scene-prompts.json` 或按同一合同保存的独立新版场景文件中，以顶层 `designStageVersion: 1` 声明美术设计阶段；每个 `locations[]` 条目的 `assetId` 继续对应计划中的稳定场景 ID，在同条记录中增加 `sceneDesign`。不要建立另一套场景身份或第二份权威 Prompt。

| 字段 | 内容 |
|---|---|
| `useAndUsers` | 空间功能、使用者与使用方式，文本中辨明脚本事实、导演方案与未知项。 |
| `scriptFacts` | 脚本明确给出的场景事实文本数组；不把导演新增物件记为脚本事实。详细原文位置与依据保存在后台。 |
| `layout` | 共用门窗、大件与通道布局文本。 |
| `furnishingLayers` | `{large:[],medium:[],small:[]}`，各为该层陈设及其位置、用途的文本数组。实际不适用的层可为空，在 `composition` 说明原因，不为凑层次增加物品。 |
| `useTraces` | 少量使用痕迹及其位置、状态的文本；需要保持整洁或无人使用时说明实际选择。 |
| `materials` | 可辨的材料差别及当前光线下的表现，文本。 |
| `composition` | 丰富区、退后区、动作与焦点留空的安排，文本；同时说明不适用的陈设层。 |
| `invariants` | 后续机位必须保持的布局、材料、固定物件、通道及其他必要限制，文本数组。 |
| `views` | `[{id,shotIds,position,visible,keepClear}]`：`shotIds` 为实际制作镜头 ID 数组；其他项分别为机位 ID、位置、可见范围和需留空的区域文本。只绑定确实使用该机位的镜头，不用源表行号冒充制作镜号。 |
| `constraintReview` | `[{original,source,decision,reason,replacement?}]`：逐项保存已有正负描述原句、来源、处理和理由；`decision` 为 `retain/narrow/remove/replace`，需要改写时给出具体 `replacement`。没有对应描述时如实记录检查结果，不伪造原句。 |

`base.text` 继续保存 Agent 独立创作的完整场景 Prompt，`sceneDesign` 不是正文生成模板；不得由程序串接上述字段形成 Prompt。原有 `projectId/sourcePlanHash`、参考关联与冻结规则继续生效。共用设计变化要核对 `base.text`、机位和实际引用该场景的分镜，不能只改结构而保留相反旧正文。

没有 `designStageVersion` 的历史场景文件沿用原合同，不自动补写或迁移；带标记的新版须覆盖已登记场景并逐场保存设计。新版 v2 计划的规则快照含本场景美术规则时，按此阶段交付；旧冻结计划不因规则新增自动回填。修订现有项目时，新版场景文件另存并保留旧文件；视频工作流使用显式 `sceneBundleRef:{path,sha256}` 选择所属版本，共享导出与视频导出均读取并校验该引用，不靠文件日期或“最新”文件名猜测采用版本。本规则不新增 CLI 入口。

## 先审查已有描述与负面约束

写场景 Prompt 之前，同时检查原场景描述、当前采用的场景及分镜 Prompt、风格说明和实际存在的负面词。重点识别“极简、纯净背景、无杂物、空房间、没有装饰”等要求与本次使用情境是否真的冲突，不只在新正文增加陈设而保留相反旧词。

- 逐项记录原句、来源或绑定对象、实际冲突和处理理由。没有冲突就保留；没有独立负面词时如实记录，不创建虚构负面字段或假装已检查不可见输入。
- 区分“视觉焦点清楚、动作区整洁”和“整个空间没有生活用品”。需要生活感时可改为“桌面保留少量正在使用的物件，人物活动区与门口通道保持畅通”，但仍须写明具体物件及位置，不能用另一句空泛形容词替代。
- 不把任何限制一律视为冲突。脚本要求的空房、用户确定的极简空间、已有参考中的固定家具、无茶几的起身通道、无泳圈的水面、禁止额外椅子的服务位置等都有可能是必要约束；不得为了装饰而否定。
- 用户明确锁定的要求和本次目标真正相互排斥时，保留原句、说明不能同时成立的具体关系并提问或标待处理；不能悄悄删除。只解决发现的实际冲突，不批量清除所有负面词。

## 共用设定与机位可见范围

每个稳定 `locationId` 保存一份共用场景设计，先确定世界中的门窗、家具、通道、材料和固定陈设，再为资产图或分镜选择机位。各机位只是同一空间的不同可见部分，不重新布置房间，不把画面左侧当作永久地理左侧。

场景 Prompt 由 Agent 根据共用设计自然写作。无场景参考时，保留本机位可见的关键布局、层次、材质和所需留空；镜头没有拍到的背墙、收纳箱或门不强塞进画面。已有确定采用的实际参考时，按[参考规则](visual-workflow.md#已有确定参考图时)使用真实绑定，仅写可见范围、拍法与必要变化；文字设定本身不等于图片参考。设计维度不能由程序机械拼成正文。

分镜沿用该场景设计，记录当前机位看到哪些固定锚点、哪些部分在画外，以及人物动作所需的通道和空区。衣物、书和杯子等只有在剧情中实际移动时才变更状态；变化应有源镜或明确导演安排，并核对后续返回镜头。镜头裁切、景深和焦点可以控制细节可见度，不能靠移动门窗、换沙发位置或增加一把椅子适配构图。

已确认设定不能原地覆盖。按现有版本与定向修订机制保存新方案、修改原因、旧设定及受影响镜头；重新核对该场景相关 Prompt、引用图和连续性，旧检查随对应内容变化失效。更新文本不表示旧图片已自动改变，也不表示用户确认了新陈设。旧项目不因规则新增自动迁移或补写；本次明确授权的修订另存版本。

## 自然正文与质量核对

场景润色与独立核对同读[共用表达及关系检查](prompt-language.md#四步表达核对)，本页只维护场景设计与连续性专用要求。

场景设计与 Prompt 不设创作字数上限，优先保证空间可执行、画面层次和跨镜一致。允许分段写足必要关系；删除重复和空泛词，不删掉布局、材料、动作通道或负面约束的必要条件。完整新场景 Prompt 进入既有“生成Prompt”表，六项完整美术设计进入“人物与场景”，长文自动续行而不裁切；直接影响理解的脚本事实与导演设定在设计正文中说明。检查过程、详细依据、逐项冲突处理及版本记录保留在后台制作日志和内部状态，不增设 Excel 技术表。

冻结前核对：六项是否有具体内容或合理不适用说明；脚本事实与导演补全是否分开；旧正负描述是否仍相互抵消；门窗、家具和服务位置是否一致；中小陈设是否有用途；痕迹是否符合使用者；材质是否可辨；人物动作区、焦点及主要轮廓是否被遮挡。程序结构检查不能证明美术质量，仍须留下具体语义核对证据；文本任务不触发出图。

例如，脚本只说“普通年轻人的卧室”，未锁定布局时，可以作为导演方案设计：床靠左侧墙，右侧靠窗是一张有木纹的书桌，桌上放打开的笔记本、台灯和水杯；椅背搭着一件外套，桌下有收纳箱。床头柜边留一根手机充电线，床尾棉质地毯有轻微褶皱。墙面为哑光涂料，床品保留柔软布纹。门口到床边保持连续通道，书桌一带承载生活信息，床边的人物动作区留空，背景小物不遮挡主要家具轮廓。此例不推断住户的真实职业或喜好，物件数量及布局不作为其他项目的固定模板。
